# Laundry-Wallah

Laundry-Wallah is a small static website demonstrating a laundry service landing page. It includes a service description, a price list, and a simple booking form (`index.html`). This repo is a minimal front-end prototype you can open locally and customize.

**Contents**
- `index.html` — main landing page with services, price list, and booking form.

**Features**
- Simple, mobile-friendly layout (HTML).
- Price list table and booking form.

Getting Started
--------------

1. Clone or download this repository to your machine.
2. Open the project folder and open `index.html` in your web browser (double-click or use your browser's File → Open).

Example (Windows PowerShell):

```powershell
cd 'c:\Users\Aaryan Kumar\Laundry-Wallah\Laundry-Wallah'
start index.html
```

Notes
-----
- The project is a static HTML page; no server or build steps are required.
- If layout elements appear side-by-side on small screens, open `index.html` and ensure the form is not wrapped inside table tags (the current version places sections vertically).

Contributing
------------
- Feel free to improve the styling by adding a CSS file (e.g., `styles.css`) and linking it from `index.html`.
- For functional booking, replace the form `action` with a working endpoint or add client-side handling.
